Fast mode for simple, well-defined tasks.

Scope: typos, renames, config updates, small obvious bug fixes (1-5 lines), boilerplate with minor changes.

Rules:
- Read the file before touching it
- Minimum change — don't touch anything not asked
- No stubs, no TODOs
- If during the task you realize it's more complex than expected, stop and say so

Output: the change only, one sentence on what you did. No explanations unless something was unclear.
